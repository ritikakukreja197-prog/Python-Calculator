# Python Calculator 🧮

A simple menu-driven calculator built using Python. This project helped me practise Python fundamentals, conditional statements, loops, user input, and exception handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation for invalid choices and non-numeric input
- Handles division by zero
- Repeats calculations until the user chooses to exit

## Technologies Used

- Python 3

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python calculator.py
```

## Example

```text
====Python Calculator=====
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

Enter your choice(1-5): 1
Enter your 1st number: 10
Enter your 2nd number: 5
Addition: 15
```

## What I Learned

- Using `while` loops to repeat a program.
- Using `if`, `elif`, and `else`-style decision logic.
- Handling invalid input with `try` and `except`.
- Preventing division-by-zero errors.
